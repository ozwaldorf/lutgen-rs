# Lutgen Studio has been replaced

The desktop GUI is no longer built or maintained. It has been replaced by
[Lutgen Web]({{ '/web' | relative_url }}), which runs the same pipeline in the
browser on the GPU.

Existing `lutgen-studio` releases remain published on crates.io and in distro
repositories, but no further versions will ship. The CLI and the `lutgen`
library are unaffected.
